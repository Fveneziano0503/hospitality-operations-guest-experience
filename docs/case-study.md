# Case study

## Objective
Demonstrate how operations and financial experience transfers to a hospitality setting without using customer work.

## Approach
Combine a one-day room-performance model with three service categories. Keep calculations transparent and distinguish contribution after selected costs from net profit. Support manual status changes instead of claiming autonomous dispatch.

## Builder contribution
Federico defined the operating questions, KPI workflow, task categories, and financial review model. The implementation is a fictional portfolio prototype, not evidence of a deployed hotel system.

## Measurement plan
For a future pilot, measure service completion times, room readiness delays, reporting effort, and estimate-to-actual cost variance. Response-time measurement requires timestamps not included in this version. Establish baseline results before reporting improvement.
